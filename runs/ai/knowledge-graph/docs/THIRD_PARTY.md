## OntoSmith

The method in this run (hash-pinned pack, cheap proposer plus blind judge, pure gates,
priced routing, a profile before spend, conformance records, the adjudication protocol) is
adapted from OntoSmith. It was rebuilt from OntoSmith's whitepaper and documents; no
OntoSmith source file is copied into this run. See `case-study.md` for what was taken and
what was not.
